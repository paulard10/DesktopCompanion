## 7. Revocation and lifetime

Editing question/scenario revokes review; Cancel, Discard, Close, renderer loss,
replacement and shutdown cancel the current generation and invalidate unused
approval. Duplicate Run/replay cannot start a second operation. New capture
sessions receive new identities and no prior question/result/permission.

The **120-second** lifetime still starts when opening the selector, including
selection/capture time. It is not extended on preview or review. The existing
controller timer remains the only preview timer. The session also checks the
absolute deadline before actions and publication if timer delivery is delayed.

Review remains valid for **at most 30 seconds**, clipped to the remaining preview
lifetime. Closing/expiry prevents a stale result from recreating UI. Sessions
without a window use the same bounded default for tests; invalid extended
deadlines are rejected. No new polling or idle timers.
