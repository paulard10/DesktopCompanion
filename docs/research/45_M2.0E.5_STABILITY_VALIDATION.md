| PID | Role | Private bytes at launch | Private bytes pre-quit | Change (MiB) | Private working set change (MiB) |

Tree private commit went from 215.30 MiB to 298.25 MiB, a rise of **82.95 MiB**. Of that, **27.19 MiB** is the new chat renderer. The chat window is created on first open and kept when hidden, so a second renderer after this session is expected. It is not a second copy of the app and it is not a stale extra chat process: there is one new renderer, parented to the same main process.

The original renderer’s private commit rose by 44.74 MiB. Its private working set rose by 1.09 MiB, and its working set fell from 68.39 MiB to 47.16 MiB. That pattern is commit growth with little extra resident private memory. One before/after pair, taken across the first real chat and animation use of a process that had just started, is not evidence of a leak.

No unexpected process multiplication. No `whisper-cli.exe`. Main, GPU, network, CLI parent, and the original renderer kept their launch PIDs. Available system memory moved from 825.7 MiB to 793.6 MiB. Both readings are under the 1,024 MiB Whisper floor, and that system change is not assigned to a companion leak.

The earlier development tree, measured with chat already open, was 244.98 MiB of private commit on different PIDs. It is a different session. It is not the baseline for this production delta.

## 8. Proposed M2.1 order

1. **M2.1A — Git baseline and repository hygiene.** First local checkpoint only when asked. Keep out `graphify-out/`, `.local-asr/`, `dist/`, logs, and key files.
2. **M2.1B — Production user controls** for optional movement, Wandering, and Neon Trail. They stay off unless the user turns them on. Do not bring back the dev tray by default.
3. **M2.1C — Persistent preferences and startup.** Remember the choices that should survive a quit.
4. **M2.1D — Windows packaging.** Installer or portable build, with `resources/speech` for the pinned Whisper files and the tray icon. The Qwen key stays user-supplied.
5. **M2.1E — Installed application validation.** A separate pass on the installed build, including Whisper only when available memory is at least 1,024 MiB.

A longer unpackaged personal trial can run alongside M2.1A. It is not a substitute for M2.1E.

No robot, eye, motion, chat, model, movement, or security change comes out of this note.
