# M2.0B.4 — Legacy facial baseline

Status: **validated on Windows.** Legacy torus eyes stay the face. Body motion continues in [M2.0C](36_M2.0C_SECONDARY_BODY_MOTION.md).

## 1. Decision

After a side-by-side look on Windows, Legacy Eyes is the face.

- Idle and Happy on the torus were preferred.
- Shape Sleeping and Shape Blink were acceptable, and they are not worth a second rig.
- Shape Eyes as a whole is not approved.

Emotional range beyond this face waits for body, head, antenna, and arm motion in M2.0C. This pass does not redraw the eyes.

## 3. Rendering path

One WebGL context. Each eye is the original torus arc (`radius 0.15`, `tube 0.06`, arc `1.22π`), built once in `createEye`. `createProceduralRobot` is still the only mesh writer. There is no second face, no shape toggle, and no `overlay:eye-rig` channel. Development and production use this same path.

## 4. Blink and sleep

- A blink still follows the existing clock and closes the arc to a level line, then reopens the expression that was already there.
- Sleep sets both eyes to the closed line and ignores cosmetic presence, including a Happy preview.
- A real presence clears the dev preview, so a preview cannot stick after voice or chat moves on.
- Expression changes still ease on the shared 180 ms blend. They do not overshoot.

## 5. Checks

`npm run typecheck` passed.

`npm run test` passed: **158** tests, including the new check that the shape files, the shape toggle, and the rig channel are gone while the torus, Idle, Happy, sleep, and blink remain. The build inside that run passed. The renderer chunk is back to 557.09 kB and still prints the existing size notice.

`npm run smoke` did **not** pass. The dev session in this workspace holds the single instance. The log was `desktop-companion: second-instance-exit` with `started=false`. That is a blocker, not a clean smoke.

## 6. What to look at

Quit `npm run dev` and start it again so the removed prototype is not still in the running window.

On the real 300×400 robot:

1. Idle looks like the preferred Legacy arch.
2. Happy looks like the preferred Legacy smile.
3. Sleeping is two clearly closed eyes, including the dev Sleeping preview.
4. A blink closes and opens smoothly.
5. Thinking, Listening, Responding, Speaking, Curious, and Error still appear from the dev preview, and none of them replaces sleep.
6. Leaving a preview, or a real chat or voice presence, does not leave the previous face stuck.
7. The dev chat has no Shape eyes or Legacy eyes switch.
8. Move, Stop, Home, wandering, Neon Trail, click-through, chat, Whisper, Pablo, and Qwen still behave as before.

## 7. Ready for M2.0C

The face baseline is this torus rig. The next milestone can add secondary motion on the body, head, antenna, and arms. It should not add another eye mesh, and sleep should keep winning over those motions the same way it wins over the face.
