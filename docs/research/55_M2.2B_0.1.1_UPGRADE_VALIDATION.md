## 9. Start with Windows registration

The registry was not edited from here. The user operated the tray checkbox.

While the entry was present, HKCU `Run\com.desktopcompanion.shell` was exactly:

`"C:\Users\Usuario\AppData\Local\Programs\DesktopCompanion\DesktopCompanion.exe"`

There were no arguments. HKLM had no value of that name. The StartupApproved value was absent, so Windows had no disable blob. No other Run value targeted this executable. The other Run names were unchanged from the baseline taken before the user reported the checkbox. `user-preferences.json` stayed 55 bytes at `2026-10-26T18:19:03.7393646Z`, with `version`, `neonTrailEnabled`, and `startAwake`, and no startup field. `startAwake` stayed independent of the Run value.

The user then reported the tray checkbox unchecked. A second read found both the Run value and the StartupApproved value absent. The other Run names were still unchanged. The installed 0.1.1 process was still running. No administrator entry was created.

This validates registration and removal. It does not validate launch at Windows sign-in. Windows was not signed out or restarted. A later read for the Git checkpoint again found both `com.desktopcompanion.shell` values absent. Start with Windows is off.
