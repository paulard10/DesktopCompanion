## 3. Security and privacy

Searched source, scripts, config, and research notes for key-shaped strings, private-key blocks, and cloud access-key prefixes. Also looked for `.env`, `.pem`, `.key`, `.bin`, `.wav`, `.exe`, and `.dll` files outside ignored directories.

No API key, `.env` file, private key, or credential file is in the set recommended below. `src/renderer/chat.ts` and the Qwen session use the name `apiKey` for the input field and the vault load. They do not store a key literal. Runtime keys stay in Electron user data through `safeStorage`, outside this tree.

`.local-asr/` is present on this machine and stays ignored. It holds the Whisper executable, DLLs, the Tiny model, and local audio, including natural recordings. Those files must not be added by path.

`docs/research/11_OMNIROUTE_FEASIBILITY.md` records this machine's npm cache directory. That is a local path, not a credential. `docs/research/13_LOCAL_ASR_PILOT.md` records public checksums of the Whisper files that were downloaded for the pilot. Those checksums are integrity pins, not secrets, and they are not repeated here. `graphify-out/` copies research text and is now ignored.

No secret value is written in this note.

| Path | Reason |
| --- | --- |
| `node_modules/` | Restored by `npm install` from the lockfile. |
| `dist/` | Restored by `npm run build`. |
| `.local-asr/` | Third-party Whisper binary, model, and local audio. Not licensed here for redistribution. |

## 6. What a clean rebuild needs

Checked toolchain in `package.json` and `README.md`:

- Windows x64. The main process exits on any other platform.
- Node.js at least 22.12.0. The README says this tree was checked on Node 24.21.0. npm 11 is what the README asks for.
- `npm install` from the lockfile. Runtime dependency is `three` 0.186.1. Dev dependencies are Electron 44.9.3, Vite 8.3.4, TypeScript 7.0.2, and the matching `@types` packages. `postinstall` downloads the Electron binary. Nothing is installed globally.
- `npm run dev` sets `DESKTOP_COMPANION_DEV=1`, starts Vite at `127.0.0.1:5173`, and launches Electron.
- `npm run build` then `npm start` is the unpackaged production launch. `start` removes the dev and smoke flags. It does not set `DESKTOP_COMPANION_MOVE`.
- Demo is the default provider. No environment variable and no API key are required for Demo, Pablo, sleep, wake, or the production tray.
- Qwen is optional. The user saves a key in the chat Connection panel. The app encrypts it with `safeStorage`. An endpoint must be an accepted Singapore Model Studio URL. Do not put that key in the repo.
- Whisper is optional. For an unpackaged run, place `ggml-tiny.bin` and `bin/whisper-cli.exe` plus the pinned DLLs in `.local-asr/`. The expected names and SHA-256 pins are in `src/main/localSpeech.ts`. A future packaged build would look in `resources/speech`. Transcription still refuses to start below 1,024 MiB available memory. Do not copy this machine's `.local-asr` directory into Git.

`npm run icons` can regenerate the tray PNGs. The current PNGs should still be committed so a checkout builds without that step.

## 7. Reproducibility limits

- `README.md` still describes the M1.5 overlay and says no AI is connected. The source and the later research notes are the accurate behavior. A README refresh is separate from this checkpoint.
- `npm install` needs network access to the npm registry and Electron's download host. The lockfile does not vendor those binaries.
- Whisper and Qwen cannot be reproduced from Git alone, by design.
- The reference images are not part of the runtime.
- This audit did not create a commit, so the checkpoint does not exist until it is approved and created.
