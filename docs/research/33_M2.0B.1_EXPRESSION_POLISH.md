# M2.0B.1 — Expression readability and transition polish

Status: **not approved.** These poses stretched the arcs and could leave sleep open. The corrective eye language is in the current `faceExpression` presets: sleep stays a closed line, and the other faces use small tilts and lifts on the same arch.

## 1. Root causes

The M2.0B poses were recorded before this change. On a 160 DIP body, one world unit is about 80 DIP. The eye arc is about 24 DIP across.

| Cue | M2.0B pose | Why it failed at desktop size |
| --- | --- | --- |
| Idle | Open 1, curve 1, lift 0, tilt 0 | Passed. Kept. |
| Curious | Left open 1.14 / lift 0.02 / tilt 0.10. Right open 0.84 / tilt -0.04 | The raised eye moved about 1.6 DIP. Too small to read as one eye higher. |
| Listening | Both open 1.10, curve 1.02, lift 0.016 | About 10 percent taller than idle. Inside the same silhouette. |
| Thinking | Left open 0.78, right open 0.96, opposing gaze | Passed against sleep. Kept. |
| Responding | Both open 1.04 plus a 0.03 breath, curve 1.06 | Same family as listening. The breath was a few percent of height. |
| Speaking | Both open 1.06, curve 1.10, lift 0.012 | Preserved in spirit. It needed its own mild smile so it is not another listening face. |
| Happy | Both open 1.08, curve 1.28, tilt ±0.18 | About 10 degrees of tilt. The arc did not read as a smile. |
| Error | Left tilt 0.20 glow 0.90. Right open 0.76 glow 0.88 | Mostly a dimmer eye. |
| Sleeping | Both open 0.045, curve 1.12, glow 0.4 | Passed. Openness and glow kept. Curve is now 1 so the shut line is level. |

The clamps made larger poses impossible: lift was limited to ±0.04 (about 3 DIP), curvature to 1.45, and openness to 1.35. Horizontal scale does not bend the torus. It only widens the tube, so a small scale change never became a smile.

Transitions looked uneven for three separate reasons:

- A blink kept applying tilt and width while the eye was already a thin line, so the line twisted and then opened into a new shape.
- Sleep snapped the target shut in about 200 ms while the body nodded over 800 ms. Wake multiplied openness by alertness and also closed with the sleep blink, so the eyes stayed shut and then popped.
- Both eyes already shared one blend, but a clamped eye could stop early. The old lift and tilt caps were tight enough to do that.

## 2. Geometry

The existing torus arc can carry these silhouettes. Radius 0.15, tube 0.06, arc `1.22π`, built once in `createEye`. Nothing is rebuilt per frame. No second mesh, no eyelid, and no model file.

What the arc cannot do is change its own bend. A smile is a wider arc, a stronger outer-corner tilt, and a small lift. A concerned eye is a flatter, more tilted arc. Those are transforms on the same mesh. The draw path floors horizontal scale at 0.35 and vertical scale at the closed-eye line, so a pose cannot collapse to zero.

## 3. Expression changes

Idle and thinking are the same numbers as the validated poses. Sleep still closes to `0.045` with glow `0.4`. Neon green is unchanged.

| Cue | New silhouette |
| --- | --- |
| Listening | Both eyes open 1.50, curve 0.86, lift 0.06, tilt 0. Taller than idle and even. |
| Curious | Left open 1.58, lift 0.085, tilt 0.16. Right open 0.88, lift 0, tilt -0.02. One eye is raised. The other stays open, so it does not read as a squint. |
| Responding | Both open 1.08, curve 1.42, tilt ±0.20. Lift rests at 0.02 and breathes by 0.035 on a 1.1 s cycle. Glow stays flat. Reduced motion drops the breath and keeps the smile. |

The allowed ranges are now openness up to 1.70, curvature 0.62–1.75, lift -0.05–0.11, and tilt ±0.48. Expression gaze stays inside ±0.12 so it does not fight the cursor.

## 4. Transition fixes

- Shape channels share one blend, `1 - exp(-dt / 200ms)`. A late frame is capped at 120 ms, which covers about 45 percent of the remaining gap and cannot finish the move or overshoot it. Most of a change is visible in under half a second.
- While a blink shuts the eye, width, lift, tilt, and expression gaze fade to a level line. The expression target is not rewritten. The smile returns as the eye opens.
- Sleep and wake drive openness from alertness. Both eyes use the same opening while asleep, and tilt falls away with that opening. Below alertness 0.92 the sleep blink is not stacked on top of that opening, so wake no longer pops. The ordinary blink still runs once the robot is awake.
- A fully closed scale is never zero, and a sleep fold does not leave a negative zero in tilt.

## 5. Performance

## 7. Manual visual validation

Use the robot at its real 300×400 size. The dev chat has the old expression buttons plus **Compare**, which holds each side of a pair for about 1.4 seconds: Idle / Listening, Listening / Responding, Thinking / Sleeping, Happy / Idle, Curious / Error. Click Compare again to stop. These controls are development-only.

Check:

1. Idle still looks pleasant, and a blink still closes and opens as a smooth line.
2. Happy reads as a smile and does not look asleep.
3. Curious is clearly one eye higher and more open. The lower eye stays open.
4. Listening is even and obviously more awake than idle.
5. Responding is a softer wider smile with a slow shared lift, not only a brighter glow.
6. Error looks concerned and uneven, still green, and not dimmed into a warning.
7. Thinking still looks awake and aside. Sleep still shuts both eyes.
8. A blink during a compare change does not twist the closed line.
9. Wake and sleep open and close with the body.
10. Move, Stop, Home, wandering, Neon Trail, click-through corners, chat, and voice still behave.

The running dev session reloaded the renderer after these edits. If a window looks stale, quit it and start `npm run dev` again. Quit that session before expecting a clean smoke.

## 8. Remaining limitations

The torus bend is fixed, so the strongest smile is a rotated wide arc and can look slightly oval rather than a drawn eyelid crease. There is still no mouth and no separate eyelid. Error stays neon green. Curious still appears whenever the robot is tracking the cursor and no stronger presence is active, so a moving pointer will show that face often. A clean smoke is still outstanding while this dev session is running.
